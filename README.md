# Computational Techniques Reference

A static, browser-based study reference for computational techniques.

## Open it

- [Hosted page](https://computational-tech.vercel.app)
- Open `comp_techniques_ref.html` locally in a browser.

## Repository

- `comp_techniques_ref.html` contains the page.
- `vercel.json` contains deployment configuration.

This is a small learning resource. No backend or package installation is required.
